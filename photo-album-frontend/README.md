# Folio frontend

Mobile-first React frontend for the photo album application. The visual
language is inspired by a physical photo album: warm paper, printed covers,
book spreads, soft shadows, and touch-friendly navigation.

## Run locally

```bash
nvm use
npm install
npm run dev
```

The current screen uses curated photo placeholders while the REST API contract
is connected. The album interactions already model the future API workflow:
select an album, page through a spread, create an album, and add photographs.
