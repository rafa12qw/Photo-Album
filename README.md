A web application designed to manage, organize, and showcase photo galleries seamlessly. This project focuses on clean component architecture, smooth user interactions, and robust state management.

---

## 📌 Overview

The Photo Album application allows users to upload, browse, and organize photos efficiently. It provides a responsive user interface with a strong emphasis on performance and clean state handling.

### 🌟 Key Features

- **Media Gallery & Grid:** Responsive layout for displaying photos cleanly across different screen sizes.
- **Upload & Management:** Seamlessly add, organize, or remove photos from collections.
- **Interactive UI:** Smooth transitions, previews, and user-friendly navigation.
- **Clean Architecture:** Well-structured components ensuring scalability and maintainability.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript / TypeScript 
- **Styling:** CSS Modules 
- **Backend / Storage:** Node.js / REST API / Local Storage / Prisma / NestJS
- **Version Control:** Git & GitHub
